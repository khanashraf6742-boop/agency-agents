# Download: CCSP Rules 2021 Batch 2 — Hinglish video

`pension_b2_hinglish_DL.mp4` is a 58 m 37 s, 1920x1080, 75.4 MB copy of the full film
(same audio, slightly smaller video bitrate so it fits through Git).

It is stored here in three parts because GitHub rejects files over 100 MB.

## Rejoin after downloading

Download `part0`, `part1` and `part2`, then:

**macOS / Linux**
```
cat pension_b2_hinglish_DL.mp4.part0 \
    pension_b2_hinglish_DL.mp4.part1 \
    pension_b2_hinglish_DL.mp4.part2 > pension_b2_hinglish.mp4
```

**Windows (PowerShell)**
```
cmd /c copy /b pension_b2_hinglish_DL.mp4.part0+pension_b2_hinglish_DL.mp4.part1+pension_b2_hinglish_DL.mp4.part2 pension_b2_hinglish.mp4
```

Verify the result (SHA-256):
```
5297403e6704874103c34c7c407fc9695826c0f4196142c38d296803ef58b903
```

The full-quality 138.9 MB master stays out of Git; it is the file
`pension_b2_hinglish_FULL.mp4` in the repository root of the working sandbox.
