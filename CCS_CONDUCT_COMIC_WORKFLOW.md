# CCS (Conduct) Rules, 1964 — Comic Mastery Workflow

Exam-oriented Hinglish comics, sequential rule by rule. Same conventions as the Leave project:
Hinglish story/dialogue, English legal terms preserved exactly, factual accuracy first,
every rule element verified against current authoritative text before rendering.

## Sources & currency
- Base rule text: referencer.in CCS(Conduct)Rules1964 rule pages (transcription of the rules + GOI Decisions index).
- Currency anchor: DoPT compilation "as amended up to 31.12.2014" (as on DoPT website 02.01.2025, via DTF index);
  no post-2014 rule amendments traced. Per-rule amendment checks continue during each rule's research.
- Scope: Rules 1–25 including inserted Rules 3-A, 3-B, 3-C. Government of India Decisions/OMs under each
  rule are indexed for context but only operative rule text is rendered unless a decision is exam-material.
